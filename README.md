# Исследование влияния достоверности контекста на формирование уверенности и выбор источника знания в больших языковых моделях

### Дарья Баранова, БКЛ221

В этом репозитории содержатся исходные и итоговые файлы, код обработки и код анализа результатов ВКР, посвященной исследованию влияния достоверности контекста на формирование уверенности и выбор источника знания в больших языковых моделях

- В директории `base` содержатся результаты проверки промптов в нейтральных условиях, полученные в результате фильтрации датасеты, а также датасеты, с данными, которые подавались моделям (`*_context_sents.csv`)
- В директориях `qwen`, `mistral`, `deepseek` содержатся датасеты с ответами моделей в разных контекстных условиях
- В директории `code` файлы с кодом предобработки исходного датасета, запуска моделей и анализа результатов
